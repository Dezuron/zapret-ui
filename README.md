Современный графический менеджер для **flowseal-zapret** — пакета
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) от **Flowseal**,
утилиты обхода DPI.

Портабельный exe **~12 МБ**, потребление RAM **~40–60 МБ** (WebView2 шарится с Edge).

> **Требования:** Windows 11 x64 (build 22000 или новее), WebView2 Runtime (в Windows 11 уже установлен),
> права администратора при запуске (нужен WinDivert). Приложение больше не поддерживает Windows 10,
> Linux и macOS.

## Возможности

- 🚀 **Обход как Windows-служба `zapret`** — принцип `service.bat` «Install Service»:
  `winws.exe` работает без консольных окон и иконок в панели задач, служба поднимается
  при загрузке Windows.
- ✈️ **Telegram WS-прокси** — локальный MTProto-прокси поверх WebSocket: включение,
  готовая `tg://proxy`-ссылка, копирование, открытие в Telegram, смена ключа,
  автозапуск вместе с приложением и обновление бинарника из приложения.
- 💾 **Запоминает последнюю стратегию** и запускает её при старте приложения.
- 🔄 **Обновление flowseal-zapret** — проверка GitHub-релиза Flowseal, changelog, скачивание,
  проверка контрольной суммы (если GitHub её публикует), распаковка и замена без ручных действий.
  Пользовательские списки и собственные стратегии сохраняются.
- 🎛 **Все стратегии** — список строится динамически из `*.bat`; новые появляются после
  обновления flowseal-zapret.
- 📥 **Автоустановка прокси** — при первом запуске бинарник скачивается сам (если включён
  автозапуск); при занятом порте есть кнопка «Занять свободный порт».
- 📊 **Проверка стратегий** — замер Discord/YouTube/контрольных хостов по TCP/TLS,
  рейтинг с баллами и вердиктами, быстрая проверка текущей стратегии, история прогонов.
- 🧪 **Подбор новых стратегий** — мутации лучших профилей, проверка 20–100 кандидатов,
  сохранение победителей в отдельную группу «Экспериментальные».
- 🛡 **Защита от неожиданностей** — подтверждения остановки/обновления/проверки,
  проверка победителя через минуту с автооткатом, атомарная запись конфига.
- 🖥 **Современный тёмный UI на русском** — Vue 3, панели с шагами, трей,
  сворачивание в трей по закрытию, клавиатурная навигация и видимый фокус.

## Стек

- **Tauri 2** (Rust) — backend, ~12 МБ exe, строгая CSP
- **Vue 3 + TypeScript + Vite** — frontend, дизайн-токены и компоненты без UI-фреймворка

## Структура

```
%LOCALAPPDATA%\zapret-ui\
├── config.json          — настройки (стратегия, автозапуск, game filter, бюджет подбора, runtime_path)
├── runtime\             — распакованный zapret по умолчанию (bin/, lists/, utils/, *.bat)
├── bench.json           — история проверок (последние 20)
├── tgws_update_cache.json — кэш проверки релизов прокси (12 ч)
├── bench_state.json     — маркер незавершённого прогона (восстановление после падения)
├── generated.json       — экспериментальные стратегии
├── tgws\                — Telegram-прокси: tgws-cli.exe, tgws.log
└── tmp\                 — временные файлы обновления
```

## Сборка

```powershell
.\scripts\build.ps1
```

Или вручную:

```powershell
npm install
npm run tauri build        # использует default target dir
# или с отдельным target:
$env:CARGO_TARGET_DIR = ".\src-tauri\target-dist"
npm run tauri build
```

Результат:

| Файл | Описание |
|------|----------|
| `zapret-ui.exe` (в корне проекта) | Готовый портабельный exe (~12 МБ), просто запускай |
| `src-tauri\target-dist\release\zapret-ui.exe` | Тот же exe (внутренняя сборка) |
| `bundle\nsis\zapret-ui_*_x64-setup.exe` | Установщик (NSIS, per-user) |
| `bundle\msi\zapret-ui_*.msi` | MSI (не собирается по умолчанию, включите `msi` в `bundle.targets`) |

> Автозапуск приложения — через Run-ключ HKCU: приложение видно в «Автозагрузке»
> Диспетчера задач и само «следует» за перемещённым exe. Запуск выполняется с правами
> администратора (нужен WinDivert); при включённом UAC Windows может показать запрос
> подтверждения при входе в систему.
>
> **Остановка обхода полностью чистит систему** (как `service.bat` «Remove Services»):
> останавливает и удаляет службу `zapret`, убивает `winws.exe` и удаляет драйвер WinDivert.
> Приложение спрашивает подтверждение перед остановкой.

## Первый запуск

1. Запусти `zapret-ui.exe` (подтверди UAC — нужны права администратора для WinDivert).
2. Если flowseal-zapret ещё не установлен, откроется мастер: приветствие → выбор папки →
   скачивание. По умолчанию предлагается `%LOCALAPPDATA%\zapret-ui\runtime`; можно выбрать
   пустую папку (например, рядом с портативным exe) или папку с уже распакованным flowseal-zapret.
3. Мастер скачает около 10 МБ с GitHub, проверит SHA-256 и распакует flowseal-zapret.
4. Выбери стратегию (например `general (ALT12)`) и нажми **Запустить обход**.
5. При желании нажми **Все стратегии** — приложение замерит Discord/YouTube и покажет
   рейтинг. Проверка занимает 2–5 минут, обход на это время останавливается.
6. Включи **Запуск при старте Windows** в настройках. Папку flowseal-zapret можно позже
   изменить там же; при запущенном обходе приложение сначала предложит его остановить.

## Проверка стратегий

- **Текущая** — быстрый замер активной стратегии без остановки обхода.
- **Все стратегии** — baseline без обхода, затем каждый кандидат временным процессом
  `winws.exe`; после проверки служба поднимается снова.
- Балл: Discord ×2, YouTube ×2, контрольные хосты ×1. Вердикты: `работает ≥90`,
  `частично 60–89`, `не работает <60`; провал контрольного хоста — `ломает интернет`.
- **Подобрать** — мутации топ-3 стратегий (20–100 кандидатов), победители сохраняются
  в группу «Экспериментальные».

## Обновление

### Приложение

- При запуске приложение проверяет `releases/latest` на GitHub (настройка «Проверять обновления приложения»).
- Если версия новее, показывается кнопка **Обновить приложение**: скачивается `zapret-ui.exe`,
  проверяется SHA-256 из GitHub `digest`, текущий exe заменяется, приложение перезапускается.
- Старая версия сохраняется как `zapret-ui_old.exe` до успешного старта новой.
- Обновление не запускается во время проверки стратегий или обновления flowseal-zapret.
- Обновляется только exe; установщик NSIS нужен для первой установки. Ярлыки и запись деинсталлятора
  при обновлении не меняются.

### flowseal-zapret

- Авто-проверка при старте (если включена) и кнопка **Проверить обновления flowseal-zapret**.
- При наличии новой версии показывается changelog и кнопка **Обновить**.
- Обновление заменяет только flowseal-zapret; пользовательские списки (`*-user.txt`)
  сохраняются, активная стратегия перезапускается.
- Если GitHub публикует `digest` ассета, архив проверяется по SHA-256 до распаковки.
- Источник: [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).

## Требования

- **Windows 11 x64**, build 22000+ (приложение проверяет это при старте).
- **WebView2 Runtime** — в Windows 11 уже установлен.
- **Права администратора** — нужны для WinDivert и службы `zapret`.
- Доступ к GitHub для скачивания flowseal-zapret и проверки обновлений.

## Приватность

- **Нет телеметрии, аналитики, аккаунтов и внешних серверов.**
- Приложение обращается только к GitHub API для проверки и скачивания обновлений
  приложения и flowseal-zapret.
- Конфиг, история проверок, списки и пользовательские настройки остаются локально.
- Никакие данные о системе, выбранной стратегии или использовании не отправляются.
