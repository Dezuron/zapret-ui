# Changelog

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-21

### Добавлено

- Новый интерфейс: sidebar, отдельная главная с управлением Zapret и Telegram,
  страницы Zapret и настроек.
- Три темы оформления — тёмная, серая и светлая; выбор сохраняется между запусками.
- Frameless-окно с собственными кнопками свернуть, развернуть и закрыть.
- Проверка обновлений приложения и flowseal-zapret одной кнопкой на главной.

### Изменено

- Кнопки стали объёмнее, а блок проверки стратегий — аккуратнее и понятнее.
- Шрифт интерфейса — Inter Variable.
- Серая тема стала светлее; у тёмной и серой убран фоновый градиент.
- Обновлены иконка, шапка и навигация приложения.

## [1.0.0] — 2026-10-21

### Добавлено

- Новый публичный репозиторий с единой чистой историей.
- Функциональность соответствует версии 1.3.1: обновления приложения и flowseal-zapret,
  мастер первого запуска, «Что нового», проверка стратегий и Windows 11 UI.

### Изменено

- Версия нового репозитория начинается с 1.0.0.
- Пользователям предыдущей версии 1.3.1 нужно один раз установить 1.0.0 вручную:
  старый updater не считает 1.0.0 более новой версией.

## [1.3.1] — 2026-10-21

### Исправлено

- В блоке обновлений при актуальной версии показывается сама версия, а не прочерк.
- Проверка обновления flowseal-zapret теперь ведёт себя как проверка приложения:
  при отсутствии обновлений показывает уведомление, без старой надписи
  «Установлена последняя версия».
- Версии приложения и flowseal-zapret показываются без префикса `v`.
- Удалена лишняя кнопка «Повторить» из результатов проверки стратегий.

## [1.3.0] — 2026-10-21

### Добавлено

- Окно **«Что нового»** после обновления: один раз показывает краткий список
  изменений текущей версии. Появляется и после чистой установки.
- Ссылка на страницу релиза из окна «Что нового».

### Изменено

- GitHub Release теперь содержит только изменения текущей версии, без полного
  технического CHANGELOG.
- Из интерфейса убрана техническая атрибуция; благодарности остаются в README
  и `THIRD_PARTY_NOTICES.md`.
- Ручные живые тесты убраны из публичного README и остаются в локальном runbook.

## [1.2.0] — 2026-10-21

### Добавлено

- Ручная кнопка **«Проверить обновления flowseal-zapret»** — доступна всегда, даже
  когда установлена последняя версия. Рядом — ссылка на upstream-репозиторий.
- Атрибуция: Flowseal (zapret-discord-youtube), bol-van (zapret), basil00 (WinDivert);
  `THIRD_PARTY_NOTICES.md` с MIT-лицензией upstream и ссылкой на WinDivert.
- Разделы «О программе» и «Благодарности» в README и приложении.

### Изменено

- «runtime» в интерфейсе переименован в **flowseal-zapret**.
- Кнопка **«Изменить»** для папки flowseal-zapret теперь работает: при запущенном
  обходе приложение предлагает его остановить, затем открывает выбор папки.
- Tauri-команды разбиты на модули `status/strategies/benchmark/updates/settings`;
  фронтенд-store — на `state/actions`.
- Ошибки Tauri-команд переведены на типизированный `AppError` (`thiserror`),
  контракт с UI сохранён (строка сообщения).

### Добавлено в тесты

- Vitest + jsdom: тесты форматирования, состояния store и смены папки с mock Tauri.
- Rust: тесты `AppError`; всего 59 тестов, 2 живых ignored.

## [1.1.2] — 2026-10-21

### Исправлено

- Release workflow больше не использует Vite-каталог `dist` для staging: в `v1.1.1`
  из-за этого в ассеты попадали `index.html` и `icon.png`. Теперь релизные файлы
  собираются в отдельный `release-artifacts`.

## [1.1.1] — 2026-10-21

### Добавлено

- ESLint и Prettier для Vue/TypeScript, скрипты `lint`, `format`, `format:check`
  и соответствующие проверки в CI и release workflow.
- Poison-safe мьютексы конфига и бенча: паника одного потока больше не роняет
  все последующие команды.
- Публичный репозиторий; из документации убраны личные пути и внутренние названия.

### Изменено

- Версия приложения 1.1.1.

## [1.1.0] — 2026-10-20

### Добавлено

- Проверка стратегий: Discord/YouTube/контрольные хосты, baseline без обхода,
  баллы и вердикты, история в `bench.json`.
- Подбор экспериментальных стратегий мутациями топ-3, группа «Экспериментальные»,
  `generated.json`.
- Применение победителя с отложенной перепроверкой и автооткатом (opt-in).
- Мастер-подсказка первого запуска: скачивание runtime в один клик.
- Дизайн-токены, панели с шагами, компоненты Vue, модальные подтверждения,
  тосты, доступность с клавиатуры.
- Нативный заголовок Windows 11 с тёмным caption и системными кнопками.
- Проверка `sha256` ассета runtime, защита от zip-slip, абсолютные пути System32.
- Автообновление приложения по схеме tg-ws-proxy: GitHub latest → SHA-256 → замена exe →
  перезапуск с ожиданием старого PID и резервной копией для отката.
- Мастер первого запуска: выбор папки runtime (по умолчанию `%LOCALAPPDATA%\zapret-ui\runtime`),
  выбор существующей папки, скачивание и установка.
- `runtime_path` в конфиге и смена папки runtime в настройках (только при остановленном обходе).
- CI: fmt, clippy, тесты и сборка фронтенда; release workflow.

### Изменено

- Версия приложения 1.1.0; версия runtime показывается отдельно.
- Остановка обхода, обновление, полная проверка и удаление экспериментальной
  стратегии требуют подтверждения.
- Клик по стратегии только выбирает её; применение — отдельной кнопкой.
- Окно 1040×720, минимум 760×560; проверка попадания на видимый монитор.
- Только Windows 11 (build ≥ 22000), без кросс-платформенных заглушек.

### Исправлено

- Zip-slip и traversal в имени ассета при обновлении runtime.
- Гонка записи `config.json`; запись теперь атомарная.
- Ошибка обновления/бенча больше не оставляет систему без обхода.
- Watchdog не поднимает обход после ручной остановки.
- Кнопка «Открыть папку runtime» работает через `ShellExecuteW`.
- Панели сайдбара не выходят за карточки на коротких/узких окнах.
- `config.json` с UTF-8 BOM больше не сбрасывает настройки при чтении.
